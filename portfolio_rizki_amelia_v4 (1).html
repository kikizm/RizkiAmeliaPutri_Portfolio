SQL Queries
menu_pricing.sql 
SELECT
  CATEGORY,
  COUNT(menu_item_id)   AS Total_Item,
  MIN(price)            AS Min_Price,
  MAX(price)            AS Max_Price,
  ROUND(AVG(price), 2)  AS Avg_Price
FROM Restaurant.menu_items
GROUP BY category
ORDER BY Avg_Price DESC;

order_volume.sql 
WITH order_size AS (
  SELECT
    order_id, order_date, order_time,
    COUNT(order_details_id) AS items_ordered
  FROM Restaurant.order_details
  GROUP BY order_id, order_date, order_time
)
SELECT
  COUNT(order_id)                    AS total_orders,
  ROUND(AVG(items_ordered), 2)       AS avg_items_per_order,
  MAX(items_ordered)                 AS max_items_in_order,
  ROUND(
    COUNTIF(items_ordered = 1) * 100.0
    / COUNT(order_id), 1)            AS pct_single_item_order
FROM order_size;
📌 Order Volume & Distribution
revenue_category.sql 
WITH category_stats AS (
  SELECT
    m.category,
    COUNT(o.order_details_id) AS total_orders,
    SUM(m.price)              AS revenue
  FROM Restaurant.order_details o
  JOIN Restaurant.menu_items    m
      ON SAFE_CAST(o.item_id AS INT64) = m.menu_item_id
  GROUP BY m.category
)
SELECT
  category, total_orders,
  ROUND(revenue, 2)                     AS total_revenue,
  ROUND(total_orders * 100.0
        / SUM(total_orders) OVER(), 1)  AS pct_volume,
  ROUND(revenue * 100.0
        / SUM(revenue) OVER(), 1)       AS pct_revenue
FROM  category_stats
ORDER BY revenue DESC;
📌 Revenue Contribution by Category
item_ranking.sql 
WITH item_stats AS (
  SELECT
    m.item_name, m.category, m.price,
    COUNT(o.order_details_id)       AS times_ordered,
    ROUND(COUNT(o.order_details_id)
          * m.price, 2)             AS est_revenue
  FROM Restaurant.menu_items m
  LEFT JOIN Restaurant.order_details o
         ON SAFE_CAST(m.menu_item_id AS INT64)
          = SAFE_CAST(o.item_id AS INT64)
  GROUP BY m.item_name, m.category, m.price
)
SELECT
  item_name, category, price,
  times_ordered, est_revenue,
  RANK() OVER (
    PARTITION BY category
    ORDER BY times_ordered DESC
  ) AS rank_in_category
FROM  item_stats
ORDER BY times_ordered DESC;

Business Problem

Finance teams struggle to identify which invoices are overdue, which vendors carry risk, and how multi-currency payables impact cash position — without a structured analytics pipeline. A 32.1% payment rate across all vendors and all 3 years signals a structural process failure, not a seasonal issue.

Root Cause
  1. No enforcement: Net 30 terms not tracked or escalated, so invoices silently aged past 90 days undetected.
  2. No accountability: 32% collection rate flat across all 3 years confirms process failure, not seasonal variance.
  3. No visibility: Without automated alerts, $1.25M overdue exposure accumulated completely undetected.
Recommendations
  • Immediate: Escalated all 468 invoices in 90+ day bucket ($1.25M) for weekly tracking + legal review beyond 180 days.
  • Vendor scorecard: Built a monthly vendor payment scorecard targeting 50% (Year 1) → 70% (Year 2).
  • Process: Designed automated reminders at 30/60/90-day thresholds + an early-payment incentive program.
  • FX hedging: Flagged currency pairs with unpaid exposure above $250K and recommended FX-adjusted consolidated reporting.
Key Insight

A 32.1% payment rate flat across 3 years is not a vendor problem — it's a broken internal process. Identified 3 root causes and delivered prioritized fixes.
